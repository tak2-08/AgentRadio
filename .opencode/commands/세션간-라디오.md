서로 다른 세션(프로세스/터미널/환경)이 협력할 때의 모델을 안내한다.

**두 전송 계층**
- **radio** = 한 세션 내 실시간 패시브 버스. `RADIO_ROOT` 동일하면 자동 공유.
- **memory** = 여러 세션 간 내구성 있는 조율 버스. GitHub 저장소 `tak2-08/memory`를 사용.
  지시/의견/상태를 `sessions/<task-id>/<role>.md`에 기록, 다른 세션은 `memory_search`/`memory_get`으로 회상.

**역할**: 팀장 세션 / 대리 세션(조율·종합·의견전달) / 팀원 하위 세션(병렬 에이전트).
**릴레이 흐름**: `user → leader → proxy → member`, `proxy → member → proxy → ...`, `leader → proxy → member → proxy → leader`.
**토론**: `/토론` — 대리 사회자, 팀원들이 이견으로 주장, 대리가 종합해 팀장에게 전달 → 팀장이 신규 업무 하달.

멀티세션은 새 터미널/프로세스, 싱글세션은 `task` 서브에이전트로 동일 모델 적용.
자세한 구조는 `skills/agent-radio/SKILL.md`의 "협력 아키텍처" 참조.
